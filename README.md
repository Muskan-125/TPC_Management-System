# TPC Management System

## Overview
The TPC Management System is a web-based placement portal designed to streamline placement-related activities by connecting students, companies, and placement administrators through a centralized platform.

## Key Features
- Student and company account management
- Job posting and job listing management
- Placement application tracking
- Role-based dashboards
- Centralized placement information

*Include only the features implemented in the current version.*

## Technology Stack
- **Frontend:** React, Vite
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Authentication:** JWT and bcrypt, if configured in the current implementation

## Project Structure
- `frontend/` — frontend application
- `backend/` — backend API and server

## Getting Started
1. Clone this repository.
2. Install the frontend and backend dependencies.
3. Configure the required environment variables.
4. Set up the database and apply the required migrations.
5. Start the backend and frontend using their respective development scripts.

Refer to the frontend and backend package files for the exact commands and dependencies.
